# راهنمای جامع راه‌اندازی پلتفرم مستقل (SaaS) مدیریت هوشمند کانال‌ها

> یک پلتفرم کسب‌وکار اشتراکی چندکاربره (Multi-Tenant) فارسی که به صورت مستقل از وردپرس روی هاست شما اجرا می‌شود.
> نسخه وردپرس قبلی شما (افزونه نسخه ۹.۷.۱) کاملاً دست‌نخورده و بدون تغییر باقی مانده است.

---

## 🚀 ویژگی‌های کلیدی پیاده‌سازی شده در نسخه ۲ (SaaS مستقل)

1. **معماری مستقل چندمستأجری (Multi-Tenant)**: جداسازی کامل داده‌های هر مستاجر بر اساس ساختار امنیتی مدرن `tenant_id` به همراه لایه دسترسی متمایز.
2. **پشتیبانی دوگانه دیتابیس (PDO)**: قابلیت اتصال به **MySQL** یا **SQLite** از طریق یک فایل پیکربندی واحد (`config/config.php`).
3. **مکانیزم ضدتقلب و قفل ابدی کانال‌ها**: اختصاص دائمی شناسه کانال‌های تلگرام و بله به اولین ثبت‌کننده در جدول جهانی `channel_registry` جهت جلوگیری از ایجاد پنل‌های آزمایشی متعدد از یک کانال.
4. **سیستم پیشرفته اشتراک‌ها و کنترل سهمیه (Quota)**: محدودسازی تعداد کانال‌های متصل و تعداد کل پست‌های ارسالی کاربران بر اساس پلن فعال آنها به همراه پلن رایگان آزمایشی اولیه (۱ تلگرام + ۱ بله + حداکثر ۱۰ پست).
5. **سیستم مالی و واریز کارت به کارت (بلو بانک)**: به درخواست شما به دلیل استفاده از لینک‌های مستقیم بلو بانک، سیستم تایید دستی رسید واریز پیاده‌سازی شده است. مستأجر فیش پرداخت خود را ثبت کرده و مدیر کل (Super Admin) پس از بررسی، فوراً با یک کلیک اشتراک کاربر را فعال می‌کند.
6. **پاسخگوی خودکار کلمات کلیدی هوشمند و صندوق پیام**: دریافت پیام‌ها با روش وب‌هوک ایمن یا سیستم Polling بدون نیاز به HTTPS (getUpdates)، تشخیص خودکار کلمات کلیدی، ارسال پاسخ آنی و آرشیو متمرکز پیام‌ها.
7. **اعلان‌های زنده موبایل (PWA & Service Worker)**: پیاده‌سازی کامل مانیفست استاندارد PWA و هندلر پس‌زمینه اعلان‌های وب‌پوش (VAPID Push API).
8. **پکیج کامل اندروید (Android Studio Ready)**: سورس‌کد کامل پروژه اندرویدی به زبان نیتیو جاوا شامل سیستم WebView پیشرفته با فعال‌سازی کامل بارگذاری تصاویر و آپلود رسید تراکنش‌ها (`onShowFileChooser`).

## 📁 ساختار پوشه‌بندی و معماری فایل‌ها

```
whcm-saas/
├── config/
│   └── config.php          # تنظیمات اصلی سامانه (دیتابیس، تایم‌زون، کلیدهای امنیت)
├── public/
│   ├── index.php          # روتر ورودی اصلی وب
│   ├── manifest.json      # مانیفست وب‌اپلیکیشن PWA
│   └── service-worker.js  # هندلر کش، آفلاین و اعلان‌های پوش
├── app/
│   ├── Core/              # هسته سامانه (Bootstrap, Auth, Csrf, Session, Router, RateLimit, HttpClient)
│   ├── Domain/            # لایه بیزینس دامین (Quota, ChannelManager, Sender, GoldTicker, Inbox, TextFormat)
│   ├── Controllers/       # کنترلرهای وب (MainController)
│   └── Views/             # صفحات کاربری، مدیریت کل و خطاها (home, dashboard, admin, errors)
├── migrations/
│   └── install.sql        # پایگاه‌داده بهینه چندمستأجره با ۱۷ جدول ساختاریافته
├── android-webview-app/   # سورس کامل پروژه اندروید استودیو جهت ساخت APK نیتیو
└── tests/
    └── IntegrationTest.php # مجموعه ۳۲ تست جامع و یکپارچه به صورت ۱۰۰٪ موفق
```

## 🛠 راهنمای گام‌به‌گام نصب و راه‌اندازی روی هاست لینوکس یا لوکال

### ۱. بارگذاری فایل‌ها بر روی هاست
تمام محتویات پوشه `whcm-saas` را در ساب‌دامین یا شاخه اصلی هاست خود آپلود کنید. (اطمینان حاصل کنید که مسیر `public` به عنوان روت وب سرور شما تنظیم شده باشد).

### ۲. پیکربندی دیتابیس (`config/config.php`)
اگر مایلید از **SQLite** استفاده کنید، سیستم به صورت پیش‌فرض در اولین اجرا دیتابیس را به طور خودکار ساخته و ۱۷ جدول مایگریشن را اعمال خواهد کرد.
اگر مایل به استفاده از **MySQL** هستید، مشخصات دیتابیس خود را در این فایل تنظیم کنید:
```php
'database' => [
    'driver' => 'mysql', // تغییر از sqlite به mysql
    'mysql' => [
        'host' => '127.0.0.1',
        'database' => 'نام_دیتابیس_شما',
        'username' => 'نام_کاربری_شما',
        'password' => 'رمز_عبور_شما',
    ]
]
```

### ۳. ایجاد حساب کاربری مدیر کل (Super Admin)
برای دسترسی به پنل مدیریت ارشد کل (`/admin`) جهت ساخت پلن‌ها و تایید پرداخت‌ها، وارد دیتابیس (یا فایل sqlite) شده و مقدار ستون `role` را برای ایمیل و کاربری که مایلید به `superadmin` تغییر دهید:
```sql
UPDATE users SET role = 'superadmin' WHERE email = 'hooman@belitia.ir';
```

### ۴. راه‌اندازی زمان‌بندی خودکار (Cron Job)
جهت دریافت خودکار پیام‌های ربات (در صورت عدم فعال بودن وب‌هوک) و همچنین به‌روزرسانی و انتشار خودکار نرخ لحظه‌ای طلا، یک کرون جاب کلی بر روی هاست لینوکس خود با فاصله زمانی ۱ دقیقه‌ای تنظیم کنید:
```bash
* * * * * php /path/to/your/whcm-saas/app/Domain/GoldTicker.php >> /dev/null 2>&1
```

## 📱 راهنمای خروجی گرفتن APK اندروید در کمتر از ۵ دقیقه!

سورس کامل اندروید درون پوشه `android-webview-app` قرار دارد. برای خروجی گرفتن کافی است مراحل زیر را انجام دهید:

1. نرم‌افزار **Android Studio** را باز کنید.
2. گزینه **Open an Existing Project** را انتخاب کرده و آدرس پوشه `android-webview-app` را بدهید.
3. فایل `MainActivity.java` را باز کنید (مسیر: `app/src/main/java/ir/belitia/whcm/MainActivity.java`).
4. متغیر ثابتی به نام `APP_URL` در خط ۱۸ قرار دارد؛ آدرس سایت یا ساب‌دامین سامانه خود را در آن وارد کنید:
   ```java
   private static final String APP_URL = "https://your-saas-domain.ir/";
   ```
5. از منوی بالای نرم‌افزار، مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید.
6. فایل خروجی APK شما با حجم بسیار کم آماده است و می‌توانید آن را در بازار، مایکت یا به صورت مستقیم به کاربران خود عرضه کنید!

## 🧪 تست‌های خودکار یکپارچگی پلتفرم

پلتفرم به همراه یک پایپ‌لاین تست جامع ۳۲تایی ارائه شده است که تمامی ابعاد احراز هویت، جلوگیری از اسپم، مبدل شمسی، ثبت کانال‌ها، ضدتقلب، صندوق پیام و کامپایل الگوهای طلا را پوشش می‌دهد. 
جهت اجرای مجدد تست‌ها بر روی سرور یا لوکال دستور زیر را اجرا کنید:
```bash
php tests/IntegrationTest.php
```
